# 🌐 Personal Portfolio Website

A modern, attractive, and responsive personal portfolio website created to showcase my frontend development skills, projects, and web development knowledge.

## ✨ Features

- 🏠 Attractive Home Section
- 👩‍💻 About Me Section
- 🛠️ Skills Section
- 💼 Projects Showcase
- 📱 Fully Responsive Design
- 🧭 Smooth Navigation
- ✨ Hover Effects and Animations
- 📧 Contact Section
- 📱 Mobile-Friendly Navigation

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📂 Sections

### Home
Introduction with my name, frontend developer role, and navigation buttons.

### Skills

- HTML
- CSS

## 🎯 Project Benefit

This portfolio helps showcase my frontend development skills and demonstrates my understanding of responsive web design, navigation, UI design, and basic JavaScript interactions.

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in any web browser.
4. The portfolio website will be displayed.
